## Current action

- Source review for each candidate's exact files and license before code adoption. `PR31` is our independent, source-pinned first implementation of atomic config files. It does **not** imply we copied or merged Nightwatch's launcher or party stack.
- The remaining critical risk is native YT **full update rollback**. A partial update may mismatch native binaries and game patches. Isolate installation in a disposable test directory, inject mid-copy failures, compare full file SHA manifest and verify restoring previous engine, launcher and INI version; do not test against real installs.
- Browser/Discord log submissions must be opt-in with a visible local scrubbed preview, not silent background uploads.
- Best native engine VRAM telemetry ideas from Nightwatch + Supermedo need independent Vulkan adaptation. Direct peer networking remains governed exclusively by YT signed-in and party authority and real 2-PC network security test.
- Do not modify real Fornex, CLS Friends, game saves, host firewall, account database, GitHub `master` or turn on any new P2P relay mode by importing this repo.
