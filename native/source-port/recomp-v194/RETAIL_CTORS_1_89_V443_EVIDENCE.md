# V443: corrected constructors 1–89 return in one Linux x86-64 probe

The owner-local build uses the same hash-pinned CUSA03173 original as V442 and the corrected first-load slot. It reassembles eight bodies (1,714 input bytes; 58 RIP-relative operands, 90 direct transfers, five virtual call sites) and translates 87 exact-matched registration bodies. The first pass enters 1–89 in original order in one process; a second pass exercises no-reinitialization behavior. No original ELF/EBOOT is loaded in the run directory; it contains only the host probe.

- Ordinal 2: translated its tail entry, heap getter and initializer, and the two vtable-selected mutex methods. Verified seven import identities against jump-slot NIDs. Used Linux pthreads and a bounded 116 MiB anonymous mapping with 2 MiB alignment. Verified heap publication, mapping bounds, recursive mutex behavior, and reuse on a second entry.
- Ordinals 3–89: translated the exact reviewed registration instruction pattern after validating the image order and relocations. The 87 bodies refer to just three shared cells and three table identities. Preserve those aliases; later constructors must not overwrite a cell after its ready flag is set.
- Testing: Clang and GCC optimized builds passed, as did the Clang ASan/UBSan host shim build and 100 fresh Clang processes. ASan caught an undersized host backing buffer during development; the original memset covers 0x488 bytes of the private heap record, so the backing storage now covers the whole region. Sanitizers do not instrument arbitrary accesses in the reassembled bodies.

This is a scoped native startup probe, not retail process startup, a playable build or cross-platform proof. It models only the relevant data and host imports; the three registration table identities do not implement their virtual methods. Unsupported paths are outside the pass claim. Corrected constructor 90 is the next boundary; it is not another instance of the registration pattern. No original bytes, private addresses, generated assembly or binary are in this commit.
