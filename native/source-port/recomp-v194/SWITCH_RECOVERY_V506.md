# V506: bounded x86-64 switch recovery
Egalito is a reference for x86-64 jump-table reconstruction and compiler-ground-truth checks; rev.ng is an independent CFG/ABI analysis candidate, not a PS4 runtime. No upstream code imported. V506 extracts a relative table and default from one exact bounded instruction sequence at a known entry, using independently supplied block starts. It neither discovers entries nor proves that callers cannot jump into the middle, and is not wired into the game dispatcher. Interior blocks are not function entries. Only a lifter preserving register/flag state may consume this as a runtime branch. Synthetic tests pass locally.
